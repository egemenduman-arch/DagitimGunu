# Kurumsal font: Biennale

Dijital Kurye Design System (Figma → Foundations / Typography) Biennale fontunu kullanır.
Biennale lisanslı bir fonttur; bu yüzden dosyaları repoda yoktur.

Lisanslı web font dosyalarını bu klasöre **aşağıdaki adlarla** koymanız yeterli —
`index.html` ve `admin.html` onları otomatik kullanır:

| Dosya | Ağırlık |
|---|---|
| `Biennale-Regular.woff2` | 400 |
| `Biennale-Medium.woff2` | 500 |
| `Biennale-SemiBold.woff2` | 600 |
| `Biennale-Bold.woff2` | 700 |

Dosyalar yokken sayfa yedek font olarak **Plus Jakarta Sans** (Google Fonts) kullanır.
